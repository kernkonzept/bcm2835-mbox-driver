# L4Re bcm2835 mailbox driver

Driver for the bcm2835 mailbox which can be found on Raspberry Pi 4. It
multiplexes firmware requests of several clients and filters requests that
change hardware properties.

# Documentation

This package is part of the L4Re Operating System Framework. For
documentation and build instructions please refer to
[l4re.org](https://l4re.org).
